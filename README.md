# Dupaco knowledge system

A system that reads five dated snapshots of a credit union's website and answers member
questions with the current value, the right tier, cited sources, a list of the site's
contradictions, and an honest "isn't listed" when the site doesn't say.

Work in progress. The approach, the rules for deciding what is "current", and the API keys
needed will be documented in `NOTES.md`.

The snapshot data is not included in this repository.
